Reading a measurement

Median, not a best-case run. Each result shows the median and observed minimum to maximum. Expand samples to inspect every measured runtime.

Latest available is not one shared revision. Each configuration retains its own measurement date, source revision and run. Branch and pull-request results are labeled separately when provided by the source.

Dates identify the evidence. Desktop dates are workflow start times, not individual sample timestamps. Mobile dates come from the device result. Mobile verification counts include the discarded warmup proof.

Unknown means unknown. Missing hardware metadata is not inferred. Logical CPU count describes the machine, not how many threads the benchmark used.
